# 지식 베이스

## 1. 지식 베이스란?

지식 베이스는 사용자가 생성하는 지식 묶음의 단위를 말하며, 타 플랫폼과 연동하는 대상이 됩니다.

![지식 관리자센터 대시보드의 지식 베이스들](https://234308570-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MVZVmVOd-5LtENUPqdq%2F-MkBeC2wVKeJ5ucpsR5V%2F-MkBenWQO1VEUGtIvOX2%2Fimage.png?alt=media\&token=c60cab09-cc52-4125-9b1e-3d28acdd88fb)

## 2. 지식 베이스 생성

지식 베이스는 지식 관리자센터의 대시보드에서 '지식 베이스 만들기' 버튼을 눌러 생성할 수 있으며, 사용자는 관리자로 500개의 지식 베이스에 속할 수 있습니다.

![대시보드의 '지식 베이스 만들기' 버튼](https://234308570-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MVZVmVOd-5LtENUPqdq%2F-MkB_QQ_39UlttPJjxsC%2F-MkBbgwNDbHevDzRZouJ%2Fimage.png?alt=media\&token=3ee0c48d-52bc-4929-b9f8-3657bce6d01f)

## 3. 지식 베이스 삭제

지식 베이스 삭제는 **마스터가 설정 페이지**에서 할 수 있습니다. 지식 베이스 삭제는 \[지식 관리자센터 > 설정> 지식 베이스 삭제] 에서 마스터만 가능합니다. 또한 삭제는 타플랫폼과 연결을 해제한 상태에서 가능하니 사전에 해제하여 주시기 바랍니다.

삭제를 신청하면 7일 후 삭제되며, 이 기간동안 삭제신청을 취소할 수 있습니다. 해당 기간이 지나면 지식 베이스는 완전 삭제됩니다.

![설정의 '지식 베이스 삭제' 영역](https://234308570-files.gitbook.io/~/files/v0/b/gitbook-legacy-files/o/assets%2F-MVZVmVOd-5LtENUPqdq%2F-MkB_QQ_39UlttPJjxsC%2F-MkBcMODFCvTTYCKMzvA%2Fimage.png?alt=media\&token=6de77596-7a15-4ab7-b32a-47d8ed1659bd)

## 3. 지식 베이스 제재/사용 중

운영 정책을 어기거나 운영상 사정으로 지식 베이스가 제재/사용 중지될 수 있습니다. 해당 경우에는 [**고객 센터**](https://cs.kakao.com/requests?service=198\&locale=ko)**를 통하여 이의 신청**을 해야합니다. 지식 베이스는 제재/사용 중지에 따라 아래와 같은 사용이 제한됩니다.&#x20;

* 지식 베이스가 제재될 경우, 연동된 모든 플랫폼과 연결이 끊기며 관리자의 해당 지식 베이스 접근이 제한됩니다.&#x20;
* 지식 베이스가 사용 중지될 경우, 관리자의 해당 지식 베이스 접근이 제한됩니다.&#x20;
