# 작업이력

챗봇 관리자센터에서 봇 작업자가 봇을 만들면서 수행한 활동들은 **작업이력** 에서 일시정보와 함께 기록됩니다. 필요시 본인이 어떤 활동들을 수행해왔는지를 작업이력 메뉴 안에서 간편하게 확인할 수 있습니다.

## 언제 사용하나요? <a href="#when_use" id="when_use"></a>

봇 생성 작업중에 혹시 모를 이슈나 장애상황이 발생할 때, 봇 작업자는 어떤 활동을 수행했는지를 확인하고, 즉시 문제 해결을 위한 원인파악을 하는데 본 이력을 유용하게 참고할 수 있습니다.

또한, 다음 그림과 같이 우측 상단의 **① 전체** 로 설정되어있는 필터를 클릭하시면 챗봇 관리자센터에서 제공하는 메인 메뉴 리스트가 나타납니다. 메인 메뉴중에서 원하시는 메뉴에 따른 작업이력 사항을 해당 필터를 통해서 확인할 수도 있습니다.

<figure><img src="https://234308570-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MVZVmVOd-5LtENUPqdq%2Fuploads%2FeZrID3JtMFzPRVFjs5sN%2Fimage.png?alt=media&amp;token=f0d40d3b-1d5e-487a-a1a2-51516382675e" alt=""><figcaption><p>작업이력 메뉴 안에서 누적된 봇 작업자 수행 목록 화면. 봇 작업자가 챗봇 관리자센터에서 수행하는 다수의 활동들이 시각별로 기록되어있습니다.</p></figcaption></figure>

## 작업 이력 한걸음 더 들어가보기 <a href="#history_more_information" id="history_more_information"></a>

봇 작업자는 위와 같이 확인된 작업 이력 박스를 클릭하여, 해당 이력안에 상세하게 어떤 내용들이 발생되었는지를 추가적으로 더 확인해볼 수도 있습니다.

<figure><img src="https://234308570-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MVZVmVOd-5LtENUPqdq%2Fuploads%2FbNjGm2G6jYX4yIky0PYC%2Faction-logs-detail.png?alt=media&amp;token=45c8eafa-9445-470a-a482-31b6be05e994" alt=""><figcaption><p>작업이력 내 작업상세 내용 출력 예시입니다.</p></figcaption></figure>

봇 작업자는 이를 ‘작업 상세’ 형태로 확인할 수 있으며,

* 이력발생 일시
* 해당 활동 수행자
* 수행자 보유 권한
* 활동 발생 메뉴
* 상세 이력 정보

의 내용들을 추가로 확인할 수 있습니다.

{% hint style="danger" %}
**Caution.**

챗봇 관리자센터안에서 봇 작업자가 해당 작업 이력 내용을 추적하여 특정 시각의 활동 단계로 작업 상태를 되돌리는(Roll-back or Undo) 기능은 제공하지 않습니다.
{% endhint %}
