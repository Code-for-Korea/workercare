# 관리자

## 관리자 메뉴 <a href="#manager_menu" id="manager_menu"></a>

관리자 메뉴에서는 새로운 작업자들을 초대하거나 관리할 수 있습니다.\
챗봇 관리자센터에 가입된 계정에 대해서만 초대할 수 있으며, 초대된 계정은 적용된 권한으로 작업자 목록에 추가됩니다.\
초대시 “가입하지 않은 사용자입니다”라는 알럿이 발생할 경우 카카오 비즈니스 가입 후 챗봇 플랫폼에 1회 진입 하였는지 확인 후 다시 한 번 관리자를 초대하여 주시기 바랍니다.

{% hint style="danger" %}
**Caution.**

별도의 확인없이 즉각 추가되므로 주의가 필요합니다.
{% endhint %}

## 커스텀 권한 생성 <a href="#create_custom_authority" id="create_custom_authority"></a>

권한에서 설명된 커스텀 권한을 생성하는 메뉴입니다. 새로운 권한을 생성하는 기능을 통해 특정 기능만 접근할 수 있는 권한을 생성할 수 있습니다. 톱니바퀴 버튼을 클릭하면 커스텀 권한을 생성하는 권한 템플릿 관리 팝업이 호출됩니다.

<figure><img src="https://234308570-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MVZVmVOd-5LtENUPqdq%2Fuploads%2FNlrVmfaazZYteN6CSP0d%2Fadmin-custom-permissions.png?alt=media&amp;token=f2a27cef-d434-4056-985b-ad63ad653d19" alt=""><figcaption><p>'봇 관리자 권한 설정'영역에서 우측의 톱니바퀴가 커스텀 권한 생성 버튼 / 권한 템플릿 관리 팝업</p></figcaption></figure>

## 작업자 권한 변경 <a href="#change_authority" id="change_authority"></a>

마스터는 아래의 드랍다운 버튼 클릭을 통해 작업자의 권한을 변경할 수 있습니다. 권한은 챗봇 관리자센터에 새로운 기능이 추가될 때, 일부 변경이 있을 수 있습니다.

<figure><img src="https://234308570-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MVZVmVOd-5LtENUPqdq%2Fuploads%2F5znsQBsm7vnJFlqMoxiY%2Fadmin-change-permissions1.png?alt=media&amp;token=a38ff2d0-01c4-41a1-ad97-cda69d6439f4" alt=""><figcaption><p>권한 설정 드랍다운 버튼 클릭한 경우</p></figcaption></figure>

정식작업자를 마스터로 위임하거나, 커스텀 권한자를 정식작업자로 임명할 때에는 해당 기능들에 대해 작업자가 가져도 되는지 신중히 결정해야합니다. 특히 마스터를 위임하게 되면, 기존의 마스터는 정식작업자로 강등되며, 이때 상황을 되돌리기 위해서는 위임된 마스터가 직접 권한 위임을 진행해야 합니다.

<figure><img src="https://234308570-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MVZVmVOd-5LtENUPqdq%2Fuploads%2FWdDsUpLcj2vHMtY7Ugas%2Fadmin-change-permissions2.png?alt=media&amp;token=c3113f18-e310-4f6c-880e-d71c6d4f97d4" alt=""><figcaption><p>마스터는 한명만 존재할 수 있습니다. 해당 팝업으로 권한을 위임합니다</p></figcaption></figure>
