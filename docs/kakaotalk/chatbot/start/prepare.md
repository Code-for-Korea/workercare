# 챗봇 관리자센터 준비하기

챗봇 관리자센터를 사용하기 위해서는 제일 먼저 카카오 계정을 준비해야 합니다.

카카오 계정으로 로그인하고, 카카오비즈니스에 가입합니다.&#x20;

가입 완료 후, 카카오 계정으로 챗봇 관리자센터에 접속하시면 챗봇 관리자센터 회원 가입 화면으로 이동됩니다. 챗봇 관리자센터 회원 가입 후 카카오톡 채널 챗봇 만들기가 가능하며, 다른 카카오 계정을 관리자로 추가하여 공동 작업을 할 수 있습니다. 보이스봇은 현재 beta 상태로 보이스봇 제휴가 완료되고 보이스봇 설계 권한을 획득하시면 보이스봇 설계가 가능합니다.

## 챗봇 관리자센터 시작하기 <a href="#start" id="start"></a>

### 봇 만들기 <a href="#make_bot" id="make_bot"></a>

챗봇 관리자센터에서 챗봇을 생성할 수 있는 버튼은 **\[채팅으로 FAQ 챗봇 쉽게 만들기]**&#xC640; **\[봇 만들기]** 버튼 두 가지입니다.

챗봇 도우미와의 대화를 통해 쉽고 빠르게 FAQ 챗봇을 만들고 싶다면 좌측에 있는 \[채팅으로 FAQ 챗봇 쉽게 만들기] 버튼을, 다양한 목적의 챗봇을 직접 만들어보고 싶다면 \[봇 만들기] 버튼을 통해 챗봇을 생성해 보세요.

봇 유형을 잘못 선택해서 만들었을 경우, 해당봇에서 발화 응답을 수정하여 다른의도의 봇 으로도 충분히 전환할 수 있습니다.

챗봇 도우미에 대한 자세한 내용은 [**시작하기 > 챗봇 도우미**](https://kakaobusiness.gitbook.io/main/tool/chatbot/start/helping_bot)를 참조하시길 바랍니다.
